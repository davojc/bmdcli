Operators and agents drive the same tool.

Every command takes --json and returns exactly one document with stable field names. Exit codes mean the same thing everywhere: 0 worked, 1 the operation failed, 2 the command was wrong. Errors go to stderr either way, so nothing has to read stdout to find out whether it succeeded. 

bmd agents --skill

Installs the whole contract as an agent skill, loaded only when a task actually involves Blackmagic hardware — never into your project's own instructions file.

Download

Prebuilt, single-file native binaries. No .NET runtime to install.

  • Windows (x64) bmd-win-x64.zip
  • Linux (x64) bmd-linux-x64.tar.gz
  • Linux (ARM64) bmd-linux-arm64.tar.gz
  • macOS (Intel) bmd-osx-x64.tar.gz
  • macOS (Apple Silicon) bmd-osx-arm64.tar.gz

Unzip it, put it on your PATH, and you're done. Verifying the download against its published checksums, the macOS first-run block, and how updates work are all on the install page.

The whole vocabulary.

Point bmd at a device once — it remembers, for your user, wherever you run it.

bmd discover --add

Or set the address by hand: bmd config set videohub.host 192.168.1.50. Add --project to pin a device to the current folder instead, or a --context to keep a second device of the same type alongside the first.

Inputs and outputs are numbered the way the front panel numbers them, starting at 1.

bmd videohub route list
What is feeding each output, right now.
bmd videohub route set 4 13
Send input 13 to output 4 — destination first, then source.
bmd videohub info
Model, protocol version, and how many inputs and outputs the hub has.
bmd videohub input list
Input numbers and their labels. output list does the same for outputs, plus their lock state.
bmd videohub input rename 3 "Camera 2"
Relabel a source on the device itself, so the front panel agrees with you.
bmd videohub output lock 4
Stop anyone else re-routing output 4. output unlock 4 releases it.
bmd videohub export show.json
Save every label and route to a file, verified against the hub. Leave the filename off to write to stdout.
bmd videohub restore show.json
Put that state back, changing only what differs. Add --dry-run to see the plan first.
bmd videohub watch
Stream changes as they happen — including ones made from the front panel or another controller.
bmd discover
Find Blackmagic devices on the local network.
bmd multiview view set 1 3
Put source 3 in view 1 of a MultiView — destination first, then source. See the MultiView guide for the rest of that command group.
bmd multiview layout 2x2
Set the window layout; format sets the output video format the same way. The device validates the value, not bmd.
bmd atem input rename 2 "Camera Two"
Name an input on an ATEM, so the label shows up in its multiviewer and in every other controller. See the ATEM guide.
bmd atem aux set 1 Stage
Point auxiliary output 1 at a source, by name or by id — the usual feed for a stage monitor or a recorder.
bmd atem context set gallery
Choose which of several switchers the commands act on. context list shows them all.
--json
On any command. One JSON document on stdout with stable field names, so scripts and agents can read it.

Every command explains itself, including units, ranges and defaults: 

bmd videohub route set --help

Anything that changes a device snapshots it first, so there is always a way back — see backups in the guide.
