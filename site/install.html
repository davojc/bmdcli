Where to put it

bmd is a single executable of about 9 MB on disk, with no installer, no runtime and no admin rights required. That is deliberate, and it is the practical difference from a desktop control application: those are the right tool at a desk with a screen, and they have to be installed and kept current on each machine that needs them.

One file goes anywhere. Copy it to the gallery PC, to the rack-room machine that has no monitor attached, to a laptop in the truck, or onto a server and reach it over SSH. The same command works in all of them, which means the machine you happen to be sitting at stops deciding what you can change. 

ssh rack-room "bmd videohub route set 4 13"

There is nothing to uninstall, either: delete the file. bmd writes only its own config, backups and update cache, all under your user's standard directories.

1. Verify your download

Every release publishes checksums.txt alongside the binaries. It lists the SHA-256 of every archive in the release, not just the one you took, so the check needs --ignore-missing — otherwise it complains about the four archives you never downloaded.

Save checksums.txt next to your download, then:

# Linux
sha256sum --ignore-missing -c checksums.txt

# macOS
shasum -a 256 --ignore-missing -c checksums.txt

A good download reports exactly one line, ending in OK:

bmd-linux-x64.tar.gz: OK

Windows has no equivalent of -c, so print the hash and compare it by eye against the matching line in checksums.txt: 

Get-FileHash bmd-win-x64.zip -Algorithm SHA256

The Hash it prints should match the checksum listed next to bmd-win-x64.zip. Case doesn't matter.

2. macOS first run

These binaries aren't notarized by Apple, so Gatekeeper blocks the first run with "bmd" cannot be opened because the developer cannot be verified. That is expected, not a sign of a bad download — and the usual right-click → Open workaround doesn't apply to command-line binaries.

After extracting, clear the quarantine attribute once:

xattr -d com.apple.quarantine bmd

Extracting in Terminal with tar xzf bmd-osx-arm64.tar.gz, rather than double-clicking the archive in Finder, avoids the flag being set in the first place.

3. Staying up to date

Once bmd is installed it keeps itself current. To install the newest release: 

bmd update

Or to find out whether one exists without changing anything: 

bmd update --check

The download is verified against the release's SHA-256 checksums before anything is replaced. If the checksum doesn't match, the update aborts and your existing binary is left untouched.

bmd also checks for a new release at most once a day and prints a two-line reminder on stderr when one appears. It never delays the command you actually ran, and it stays quiet when output is piped or --json is in play. To switch it off: 

bmd config set update.check false

Windows: a running bmd.exe can't be overwritten, so an update renames it to bmd.exe.old and moves the new one into place, clearing the old file on a later run. If an update is interrupted at exactly the wrong moment you can be left with bmd.exe.old and no bmd.exe — renaming it back restores the previous version.
