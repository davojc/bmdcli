bmd

Command-line control for Blackmagic Videohub routers.

  • ✓ Videohub — fully supported: routing, labels, locks, backups, live watch.
  • … HyperDeck and ATEM — not implemented yet.

See it work

A real session against a Videohub on the local network. Assumes the hub's address is already configured — see Quick start below. 

$ bmd discover
NAME                               TYPE      ADDRESS
Blackmagic Smart Videohub 40 x 40  videohub  192.168.4.100:9990
$ bmd videohub route list
OUT  OUTPUT LABEL            IN  INPUT LABEL
1    Projector AR            1   FoH Sw PGM
2    Projector AL            1   FoH Sw PGM
3    Stage Screen            1   FoH Sw PGM
4    FoH MV 1                3   FoH Sw MV
5    #5                      13  Switcher PGM
… 35 more outputs …
$ bmd videohub route set 4 13
output 4 (FoH MV 1): FoH Sw MV → Switcher PGM
Backup: ~/.local/state/bmd/backups/192-168-4-100_blackmagic-smart-videohub-40-x-40/20260829-143512.json

Every mutating command backs up the device first — see the Videohub guide for where those files live.

Download

Prebuilt, single-file native binaries. No .NET runtime to install.

  • Windows (x64) bmd-win-x64.zip
  • Linux (x64) bmd-linux-x64.tar.gz
  • Linux (ARM64) bmd-linux-arm64.tar.gz
  • macOS (Intel) bmd-osx-x64.tar.gz
  • macOS (Apple Silicon) bmd-osx-arm64.tar.gz

Each release also publishes checksums.txt. Verify what you downloaded before running it: sha256sum -c checksums.txt on Linux, or shasum -a 256 -c checksums.txt on macOS.

Quick start

  1. Point bmd at your Videohub — either find it automatically and save it: 
    bmd discover --add
    or set the address directly if you already know it (or discovery doesn't reach it — see the guide's known limitations): 
    bmd config set videohub.host 192.168.1.50
  2. Confirm it worked: 
    bmd videohub route list
  3. Every command documents itself: 
    bmd videohub route set --help

This page only shows a slice of what bmd does. The Videohub guide covers every command, the backup/restore workflow, scripting with --json, and troubleshooting.
