bmd

Route video from the command line.

One native binary for Blackmagic Videohub routers. Nothing to install alongside it, no runtime, no SDK. Every command documents itself and every command speaks --json, so operators and agents drive exactly the same tool.

Download

Prebuilt, single-file native binaries. No .NET runtime to install.

  • Windows (x64) bmd-win-x64.zip
  • Linux (x64) bmd-linux-x64.tar.gz
  • Linux (ARM64) bmd-linux-arm64.tar.gz
  • macOS (Intel) bmd-osx-x64.tar.gz
  • macOS (Apple Silicon) bmd-osx-arm64.tar.gz

Each release also publishes checksums.txt, listing the SHA-256 checksum of every archive in the release — not just the one you downloaded. Save it alongside your download, then verify with --ignore-missing so the check doesn't complain about the four archives you don't have: 

# Linux
sha256sum --ignore-missing -c checksums.txt

# macOS
shasum -a 256 --ignore-missing -c checksums.txt

A good download reports exactly one line, ending in OK:

bmd-linux-x64.tar.gz: OK

Windows has no equivalent of -c — print the hash instead and compare it by eye against the matching line in checksums.txt: 

Get-FileHash bmd-win-x64.zip -Algorithm SHA256

The Hash it prints should match (case doesn't matter) the checksum listed next to bmd-win-x64.zip.

macOS: these binaries aren't notarized by Apple, so Gatekeeper blocks the first run with "bmd" cannot be opened because the developer cannot be verified. That's expected, not a bad download — and the usual right-click → Open workaround doesn't apply to command-line binaries. After extracting, clear the quarantine attribute once: 

xattr -d com.apple.quarantine bmd

Extracting with tar xzf bmd-osx-arm64.tar.gz in Terminal, rather than double-clicking the archive in Finder, avoids the quarantine flag being set in the first place.

Quick start

  1. Point bmd at your Videohub — either find it automatically and save it: 
    bmd discover --add
    or set the address directly if you already know it (or discovery doesn't reach it — see the guide's known limitations): 
    bmd config set videohub.host 192.168.1.50
  2. Confirm it worked: 
    bmd videohub route list
  3. Every command documents itself: 
    bmd videohub route set --help

Once bmd is installed, it keeps itself current: run bmd update to install the newest release, or bmd update --check to see whether one exists without changing anything. Downloads are verified against the release's SHA-256 checksums before anything is replaced.

bmd also checks for a new release at most once a day and prints a two-line reminder when one appears. To turn that off: bmd config set update.check false.

Windows: after an interrupted bmd update, it is possible to be left with bmd.exe.old and no bmd.exe. Renaming bmd.exe.old back to bmd.exe restores the previous version.

This page only shows a slice of what bmd does. The Videohub guide covers every command, the backup/restore workflow, scripting with --json, and troubleshooting.
